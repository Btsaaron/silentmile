# Silent Mile - Movie Production Website

Welcome to **Silent Mile**, a personal movie production website that showcases our work, vision, and way of storytelling. This is a front-end project built with HTML and CSS.

## 🔥 Features

- Hero banner with background image and mission tagline
- About section describing the production brand
- Projects section displaying featured films
- Contact form (integrated with Formspree to receive emails)
- Responsive layout
- Smooth modern design
